# 词光纯 Rust 客户端实施计划

执行分支：`feat/nsh-client-design`。界面默认采用「暖纸图鉴」，保留桌面专注学习布局；星图先按已提出的 2D Rust 路线实现。

## 已确定的产品约束

- 自有 UI、状态、业务逻辑、调度和平台适配均使用 Rust + NSH，不使用 TSX、React 或网页套壳。
- 桌面覆盖 macOS / Windows / Linux；移动端覆盖 Android / iOS，并适配窄屏、横屏和安全区。
- 7,298 词条及所有插画、英音、美音、例句音频和现有音效随安装包携带；首次启动无需联网，不增加资源下载入口。
- 无账号、无追踪、本地优先；现有网页继续可用，数据源与媒体内容保持统一。
- 保留网页 JSON 备份的导入导出能力；不默认加入云同步，不重新生成学习内容。

## 工程结构与依赖规则

`native/` 是独立 Cargo workspace，NSH 固定为 `0.3.0`，依赖由 `Cargo.lock` 锁定。`atlas-domain` 负责领域模型与学习行为；`atlas-storage` 负责验证、事务保存、恢复与备份；`atlas-media` 负责安装包资源标识与完整性；`word-atlas-native` 负责 NSH 根组件、页面、平台外壳与原生服务适配。前三层不依赖 NSH。测试工具不进入发布运行时。

资源使用 NSH asset registry 随包复制，不将约 708 MB 的音视频编成 Rust 字节常量；词库 JSON 作为内置只读内容。开发版读取仓库资源，发布版通过相同资源标识读取安装包。打包后必须核对实际媒体数量、路径和字节数。
